1. КОНЦЕПЦИЯ И ВИДЕНИЕ
================================================================================

1.1. Что такое FoosRPG

FoosRPG — прогрессивное веб-приложение (PWA) для любителей и профессионалов
настольного футбола (кикера). Это не просто трекер матчей, а RPG-платформа,
где игрок прокачивает персонажа, участвует в рейтинговых боях, турнирах-рейдах
и тренировках-квестах.

Ключевая метафора: кикер = RPG. Ты — персонаж. Матчи — битвы. Турниры — рейды.
Тренировки — прокачка скиллов. Academy — древо талантов.

1.2. Ценностное предложение

- Для новичков: понятный путь от нуля до уверенного игрока через древо
  талантов и ежедневные квесты.
- Для любителей: рейтинг, дивизионы, сезоны, комьюнити, турниры.
- Для про: турнирная система, аналитика, шаринг результатов, статус.
- Для всех: установка в один тап, работает оффлайн, не нужно скачивать
  из сторов.

1.3. Уникальные преимущества (USP)

1. RPG-метафора — первое такое приложение в нише кикера.
2. PWA — установка без App Store / Google Play.
3. ELO + дивизионы + сезоны — киберспортивная составляющая.
4. Древо талантов — визуальный прогресс.
5. Тренировки с наградами — мотивация через стрики, XP, сундуки.
6. Турниры с пересчётом рейтинга.
7. Социальная лента, клубы, челленджи.
8. Battle Pass и косметика без pay-to-win.

1.4. Ключевые метрики успеха

- DAU/MAU >= 25%.
- Retention D1 >= 40%, D7 >= 20%, D30 >= 10%.
- Средний стрик >= 5 дней.
- Матчей на пользователя в неделю >= 3.
- Установок PWA >= 60% от активных пользователей.
- Lighthouse PWA score >= 95.

2. ЦЕЛЕВАЯ АУДИТОРИЯ И СЦЕНАРИИ
================================================================================

2.1. Персоны

Персона 1: Алекс, 24, офисный работник
- Играет в кикер в офисе с коллегами.
- Хочет расти, но не знает, как.
- Сценарий: открывает FoosRPG в обед, проходит Daily Challenge, играет
  товарищеский матч, вечером смотрит урок в Academy.

Персона 2: Марина, 31, капитан любительской команды
- Играет в барах, участвует в локальных турнирах.
- Хочет видеть статистику, организовывать турниры.
- Сценарий: создаёт турнир в FoosRPG, приглашает команды, после турнира
  смотрит recap и шарит карточку.

Персона 3: Дмитрий, 38, полупро
- Участвует в региональных соревнованиях.
- Хочет следить за рейтингом, анализировать слабые зоны.
- Сценарий: после каждого матча смотрит Foos DNA, тренирует слабые навыки,
  участвует в сезонной лиге.

2.2. Ключевые сценарии использования

1. Быстрый вход: открыл PWA -> залогинился -> увидел Trick of the Day ->
   прошёл Daily Challenge.
2. Матч: выбрал тип матча -> нашёл соперника -> сыграл -> получил ELO
   и награды -> шарит карточку.
3. Турнир: создал турнир -> пригласил игроков -> жеребьёвка -> матчи ->
   финал -> пересчёт рейтинга.
4. Тренировка: открыл план -> выполнил drill -> отметил -> получил XP
   и монеты -> поддержал стрик.
5. Обучение: открыл древо талантов -> выбрал трюк -> посмотрел видео ->
   отметил «освоено» -> разблокировал следующий.

3. ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ
================================================================================

3.1. Модуль «Аутентификация и онбординг»

- Регистрация: email + пароль, Google OAuth, Apple OAuth.
- Восстановление пароля через email.
- Онбординг (первый вход):
  - Выбор ника, аватара.
  - Выбор класса персонажа (Striker / Guardian / Playmaker / Trickster /
    Tactician) — с описанием и иконкой.
  - Выбор уровня: новичок / любитель / продвинутый / про.
  - Выбор целей: «научиться базовым движениям», «прокачать рейтинг»,
    «участвовать в турнирах».
  - Выбор позиции: вратарь / защитник / нападающий / универсал.
  - Инструкция по установке PWA (для iOS — «Поделиться -> На экран Домой»,
    для Android — install-баннер).
- Гость (можно попробовать без регистрации, но без сохранения прогресса).

3.2. Модуль «Профиль персонажа»

- Аватар (генеративный или загружаемый, кроп в кружок).
- Ник, страна/город, био.
- Класс персонажа + иконка + описание.
- Уровень персонажа (XP-бар, шкала до следующего уровня).
- ELO-рейтинг + дивизион (Bronze -> Silver -> Gold -> Platinum -> Diamond ->
  Master -> Legend).
- Карта навыков (radar chart): пас, удар, защита, контроль, трюки,
  позиционирование.
- Экипировка: рамка аватара, скин стола, мяч, празднование гола, титул.
- Инвентарь: Foos Coins, сундуки, бусты, билеты на турниры.
- Достижения (сетка бейджей, locked/unlocked).
- Квесты (daily / weekly).
- Heatmap активности (как GitHub).
- История матчей с фильтрами (рейтинговые / товарищеские / турнирные /
  тренировочные).
- Foos DNA — авто-генерируемый стиль (текст + иконка).
- Кнопки: «Поделиться профилем», «Настройки», «Выйти».

3.3. Модуль «Матчи»

Типы матчей:
- Рейтинговый (ELO).
- Товарищеский (без ELO).
- Приватный (по коду/ссылке).
- Турнирный (внутри турнира).
- Тренировочный (с ботом).

Форматы:
- 1v1, 2v2.
- До 5 / 7 / 10 голов.
- Best of 3 / 5.

Логика матча:
- Лобби: выбор типа, формата, ставки (опционально).
- Matchmaking: подбор по ELO (+-200), региону, формату.
- Экран матча: счёт, таймер, лог событий (гол, ассист, ошибка).
- Ручной ввод счёта (поскольку это кикер — матчи офлайн, приложение
  фиксирует результат).
- Подтверждение результата обоими игроками (или только инициатором,
  если соперник не зарегистрирован).

После матча:
- Match Recap: счёт, статистика, изменение ELO.
- Награды: XP, Foos Coins, шанс дропа предмета.
- Кнопки: «Реванш», «Добавить в друзья», «Поделиться карточкой».

3.4. Модуль «Турниры»

Форматы:
- Single Elimination.
- Double Elimination.
- Round Robin.
- Swiss.
- Сезонная лига.

Создание турнира:
- Название, описание, обложка.
- Приватный / публичный.
- Формат, число игроков (4/8/16/32).
- Взнос Foos Coins -> призовой фонд.
- Рейтинговые ограничения (например, только Silver+).
- Регион, дата/время.
- Авто-жеребьёвка.
- Расписание матчей.

Проведение:
- Сетка (визуально — tree для elimination, таблица для round robin).
- Обновление результатов в реальном времени.
- Уведомления игрокам.

После турнира:
- Пересчёт ELO по каждой игре + бонус за место (x1.2 за 1-е место).
- Отдельный Tournament Rating.
- Награды: титул, рамка, бейдж, монеты, эксклюзивный скин.
- MVP турнира по статистике.
- Турнирный дневник (авто-карточка для шаринга).

3.5. Модуль «Тренировки»

Типы:
1. Drill-сессии (упражнения: пас в стену 50 раз, удары, трюки).
2. Solo Challenge («10 голов за 3 минуты»).
3. Shadow Match (против бота с подсказками).
4. Partner Session (совместная с другом).
5. Daily Challenge (задание дня).

Механика:
- Streak-система (7/30/100 дней -> множители XP).
- XP и уровни персонажа.
- Foos Coins за тренировки.
- Сундуки (random reward) за недельный план.
- Персональный план на основе слабых зон карты навыков.
- Челленджи от друзей.
- Достижения за упорство.

Верификация:
- Ручная отметка (honor-system).
- Фото/видео по желанию.
- Видео-верификация для ачивок.
- Оффлайн-режим: тренировки сохраняются в IndexedDB, синк при возврате
  в сеть.

3.6. Модуль «Academy»

Древо талантов:
- Ветки: Пас, Удар, Трюки, Защита, Позиционирование.
- Узлы открываются последовательно.
- Уровни: Beginner -> Intermediate -> Advanced -> Pro -> Legend.
- Легендарные трюки требуют выполнения челленджа.

Карточка движения:
- Видео (сверху, сбоку, замедленно).
- Пошаговая инструкция.
- Типичные ошибки.
- Упражнение для отработки.
- Кнопка «Отметить как освоено» -> +XP и разблокировка следующего.

Дополнительно:
- Trick of the Day.
- Видео-разбор (загрузи клип -> фидбек).
- Мастер-классы от про (премиум).
- Quiz-режим.

3.7. Модуль «Социальное»

- Друзья, подписки, чаты.
- Клубы/гильдии (создание, вступление, клубный рейтинг).
- Лента активности (матчи, ачивки, тренировки).
- Челленджи.
- Локальные лидерборды (город, бар, клуб).
- Поиск соперника рядом (геолокация, опционально).
- Шаринг результатов в соцсети (Web Share API).

3.8. Модуль «Экономика»

- Foos Coins (зарабатываются и тратятся).
- Магазин: косметика, бусты, билеты на турниры, сундуки.
- Подписка FoosRPG+.
- Battle Pass (сезонный).

3.9. Модуль «Настройки»

- Профиль: изменение ника, аватара, био.
- Приватность: видимость профиля, статистики, матчей.
- Уведомления: push, email, in-app.
- Язык: русский, английский.
- Тема: тёмная (по умолчанию), светлая.
- Аккаунт: смена пароля, удаление аккаунта.
- PWA: инструкция по установке, управление кэшем.

6. ИГРОВЫЕ СИСТЕМЫ
================================================================================

6.1. ELO-рейтинг

Формула:
  R_new = R_old + K * (S - E)
  E = 1 / (1 + 10^((R_opp - R_old) / 400))

Где:
- R — рейтинг.
- K — коэффициент (новички 40, опытные 24, топы 16).
- S — результат (1 победа, 0.5 ничья, 0 поражение).
- E — ожидаемый результат.

Модификаторы:
- Бонус за апсет: x1.1, если разница > 200.
- Штраф за неактивность: -5 ELO/неделя после 30 дней.
- Бонус за серию побед: +10% за 3+ подряд.

Дивизионы:
- Bronze: 0–999.
- Silver: 1000–1199.
- Gold: 1200–1399.
- Platinum: 1400–1599.
- Diamond: 1600–1799.
- Master: 1800–1999.
- Legend: 2000+.

Сезоны:
- 3 месяца.
- Soft reset: R_new = 1000 + (R_old - 1000) * 0.7.
- Награды за финальный дивизион.

6.2. XP и уровни персонажа

Источники XP:
- Матч: 20 XP (победа 30).
- Тренировка: 10–50 XP.
- Daily Challenge: 30 XP.
- Урок Academy: 20 XP.
- Турнир: 100+ XP.

Формула уровня:
  XP_to_next = 100 * level^1.5

- Уровень 1 -> 2: 100 XP.
- Уровень 10 -> 11: ~3162 XP.
- Уровень 50 -> 51: ~35355 XP.

Награды за уровень: монеты, косметика, бусты.

6.3. Стрики

- День считается активным, если выполнена >= 1 тренировка или матч.
- Множители: 7 дней x1.2, 30 дней x1.5, 100 дней x2.
- Заморозка стрика (1 раз в неделю, стоит монеты).
- Восстановление стрика (премиум).

6.4. Foos Coins

Заработок:
- Матч: 10–50.
- Тренировка: 5–30.
- Daily Challenge: 20.
- Турнир: 50–500.
- Квесты: 10–100.

Траты:
- Косметика: 100–2000.
- Бусты: 50–200.
- Билеты на турниры: 100–500.
- Сундуки: 200–1000.

6.5. Карта навыков

6 осей: пас, удар, защита, контроль, трюки, позиционирование.
- Значения 0–100.
- Растут от тренировок, матчей, освоенных уроков.
- Влияют на Foos DNA и рекомендации.

6.6. Foos DNA

Авто-генерация стиля на основе:
- Карты навыков.
- Статистики матчей.
- Предпочитаемых движений.

Примеры:
- «Trickster-одиночка с уклоном в левый фланг».
- «Guardian-стена, любит прессинг».
- «Playmaker-командный, много ассистов».

6.7. Древо талантов

- 5 веток x 10–15 узлов.
- Каждый узел = движение/навык.
- Открывается после освоения предыдущего.
- Легендарные узлы требуют челленджа.

6.8. Достижения

Категории:
- Матчи (первая победа, 100 побед, апсет).
- Тренировки (7-дневный стрик, 1000 пасов).
- Academy (10 освоенных движений, легендарный трюк).
- Турниры (первый турнир, финалист, чемпион).
- Социальные (10 друзей, клуб).
- Секретные.

6.9. Квесты

Daily:
- Сыграй 1 матч.
- Пройди 1 тренировку.
- Освой 1 урок.
- Выполни Daily Challenge.

Weekly:
- Сыграй 5 матчей.
- Прокачай навык на +5.
- Участвуй в турнире.
- Пригласи друга.

6.10. Battle Pass

- Сезонный (3 месяца).
- Бесплатный + премиум трек.
- Награды: косметика, монеты, бусты, эксклюзивы.
- Прогресс через квесты и матчи.

10.2. Service Worker

Стратегии:
- App Shell: precache (HTML, CSS, JS, шрифты, иконки).
- API GET: stale-while-revalidate.
- API POST/PATCH: network-only с очередью при оффлайне (Background Sync).
- Изображения: cache-first с fallback.
- Видео: cache-first с ограничением по размеру.

События:
- install — precache shell.
- activate — очистка старого кэша.
- fetch — маршрутизация запросов.
- push — показ уведомления.
- notificationclick — открытие нужного экрана.
- sync — отправка отложенных действий.
- periodicsync — обновление данных (опционально).

- IndexedDB (Dexie) для локальных данных: тренировки, черновики матчей,

- Очередь действий при оффлайне -> синк при возврате.
- Оптимистичные обновления UI.

16. ГОТОВЫЙ ПРОМПТ ДЛЯ АГЕНТА
================================================================================

Задача: разработать PWA-приложение FoosRPG — RPG-платформу для настольного
футбола (кикера).

Формат: Progressive Web App. Устанавливается на iOS и Android из браузера.
Работает оффлайн. Поддерживает push-уведомления. Проходит Lighthouse PWA >= 95.

Стек:
- Frontend: React 18 + Vite + TypeScript, Tailwind CSS + shadcn/ui,
  Framer Motion, TanStack Query, Zustand, Dexie.js (IndexedDB),
  Socket.io-client, Recharts, Vite PWA Plugin (Workbox),
  React Hook Form + Zod, i18next.
- Backend: NestJS + PostgreSQL + Prisma + Redis + Socket.io + BullMQ,
  S3-совместимое хранилище (Cloudflare R2), Web Push (VAPID),
  Supabase Auth / Lucia.
- Infra: Docker, Fly.io / Railway, Cloudflare CDN, GitHub Actions,
  Sentry, PostHog.

Ключевые модули:
1. Auth + онбординг: email/Google/Apple, выбор класса (Striker / Guardian /
   Playmaker / Trickster / Tactician), уровня, целей, позиции;
   инструкция по установке PWA.
2. Профиль персонажа: аватар, ник, класс, уровень (XP), ELO, дивизион,
   карта навыков (radar), Foos DNA, экипировка, инвентарь, достижения,
   квесты, heatmap, история матчей.
3. Матчи: рейтинговые (ELO), товарищеские, приватные, турнирные,
   тренировочные; 1v1 и 2v2; форматы до 5/7/10 голов, Bo3/Bo5;
   matchmaking; post-match recap с наградами.
4. Турниры: single/double elimination, round robin, swiss, сезонная лига;
   авто-жеребьёвка; пересчёт ELO + бонус за место; MVP; турнирный дневник.
5. Тренировки: drill-сессии, solo challenges, shadow match, partner session,
   daily challenge; стрики; XP; Foos Coins; сундуки; персональный план
   на основе слабых зон; оффлайн-режим.
6. Academy: древо талантов (5 веток: Пас, Удар, Трюки, Защита,
   Позиционирование), уровни Beginner -> Legend, видео, пошаговые
   инструкции, типичные ошибки, отметка «освоено», Trick of the Day,
   видео-разбор, quiz.
7. Социальное: друзья, клубы, чаты, лента активности, челленджи,
   лидерборды, геолокация, Web Share API.
8. Экономика: Foos Coins, магазин (косметика, бусты, билеты, сундуки),
   подписка FoosRPG+, Battle Pass.
9. Уведомления: push (Web Push VAPID), in-app, email; настройки.
10. Настройки: профиль, приватность, уведомления, язык, тема, аккаунт, PWA.

PWA-требования:
- Manifest с иконками (192, 512, maskable), screenshots, shortcuts,
  share_target, protocol_handlers.
- Service Worker (Workbox): App Shell precache, stale-while-revalidate

  notificationclick.

ПРИЛОЖЕНИЕ A. ПРИМЕР ELO-РАСЧЁТА
================================================================================

Игрок A: 1200 ELO, K=24
Игрок B: 1400 ELO, K=24

E_A = 1 / (1 + 10^((1400-1200)/400)) = 1 / (1 + 10^0.5) = 0.24
E_B = 1 - 0.24 = 0.76

A побеждает (S_A=1, S_B=0):
R_A_new = 1200 + 24 * (1 - 0.24) = 1200 + 18.24 = 1218
R_B_new = 1400 + 24 * (0 - 0.76) = 1400 - 18.24 = 1382
